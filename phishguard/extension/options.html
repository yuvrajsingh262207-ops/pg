PHISHGUARD SENTINEL

Protection settings

Navigation analysis sends the hostname and path to the configured PhishGuard backend. Userinfo, query values and fragments are stripped before sending; only their presence and query length are sent as structural metadata. The backend parses locally and does not fetch the destination. The original destination is held in extension session storage until a warning is dismissed or continued.

Permission explanation

The extension reads top-level navigation destinations to check URLs, uses tab navigation to show warnings, and stores settings. It does not read page contents, passwords, cookies, or form fields. “All sites” host access is required for broad navigation monitoring. This site-access grant also covers requests to the configured backend. The extension does not request access to page contents.
