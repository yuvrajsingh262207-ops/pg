PhishGuard Sentinel browser extension

Install the Chromium Manifest V3 extension to check top-level browser navigations independently of this dashboard. The extension calls the local PhishGuard endpoint and does not store visits in manual history.

Download Sentinel extension (.zip)

  1. Extract the ZIP file.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extracted phishguard-sentinel folder.
  4. Open Sentinel settings and save the local API address. Site-access permission is used for both navigation checks and the configured backend.

Permissions: broad site access plus navigation events are required to inspect destinations across sites; tab access displays warnings; storage saves settings. The extension does not read page content, passwords, cookies, or forms. Warnings are asynchronous and may appear after a destination begins loading; synchronous pre-navigation blocking is not guaranteed. Strict mode uses a lower threshold. Local-only mode uses a bundled URL-heuristics detector without contacting the backend; ML and external reputation checks are unavailable.

Privacy and deployment

  • Submitted URLs are parsed locally; the application does not fetch or execute them.
  • Query values and fragments are stripped before backend submission; review URL paths for sensitive data.
  • SQLite history is local and has no user separation or authentication.
  • Before public deployment, add authentication, HTTPS, distributed rate limits and retention controls.
  • Do not paste password reset links, private tokens, or credentials into the scanner.
